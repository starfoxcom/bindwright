# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, keep criticism about the work, and leave out harassment, personal attacks and discrimination of any kind. It applies in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

Report a problem privately to the maintainer through the contact on [their GitHub profile](https://github.com/starfoxcom), or with GitHub's **Report content** option on the comment or issue. Reports are kept confidential.

## Enforcement

The maintainer reviews every report and may remove content, warn, or block a person from the project, following the Covenant's enforcement guidelines.
