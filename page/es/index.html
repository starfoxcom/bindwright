Qué cambia

  • Claude olvida cómo trabajas en cada sesión Claude deja de repetir errores Lee tus reglas al inicio de cada sesión, así las funciones pequeñas y las pruebas reales dejan de ser algo que tienes que pedir cada vez.
  • Los cambios se integran sin que nadie los revise Cada pull request se revisa Una IA revisa cada cambio antes de integrarlo, y si la revisión no pasa, nada entra.
  • Cada sesión empieza desde cero Las sesiones siguen donde se quedaron Cada sesión empieza con un plan y termina con una nota para la siguiente, así el trabajo sigue justo donde se quedó.
  • Un comando equivocado puede borrar tu rama principal Los comandos peligrosos se bloquean Los push forzados a tu rama principal se detienen antes de ejecutarse, ya que un comando equivocado ahí te puede costar días de trabajo.
  • El modelo más caro escribe cada línea Un ayudante barato escribe el código Un modelo pequeño y barato escribe el código que tus pruebas pueden comprobar, y el modelo principal lo planea y revisa el resultado. En 24 trabajos medidos en dos proyectos, 23 pasaron todas las comprobaciones a la primera, por un costo estimado de un tercio. Puedes apagarlo al configurar.
  • Tienes que vigilar el CI y los límites del plan Sigue trabajando mientras no estás Vigila el CI e integra en cuanto pasan todas las comprobaciones, se pausa cerca del límite de tu plan y retoma después del reinicio, y conserva tus palabras cuando el contexto se llena, así el trabajo avanza sin ti.
  • Claude abre archivo tras archivo para encontrar una función Encuentra el código antes de leerlo Una herramienta de búsqueda indexa tu código, así en proyectos grandes encuentra una función y quién la llama cerca de un cuarto más rápido, por unos pocos tokens más. Puedes quedarte con la búsqueda integrada.
  • Su código no se parece al tuyo Escribe como tú Con tu permiso aprende cómo escribes código a partir de tus repos, luego escribe así con los puntos débiles corregidos, y la documentación que escribe usa palabras claras en vez de jerga.

          Instalar
          
    
          
      
      
    
          
    
          
    
            
      
          1. 
        
            En tu computadora, una vez
          Agrega los comandos /bindwright a todos tus proyectos. No necesita Git.
            
        
            /plugin install bindwright --marketplace https://starfoxcom.github.io/bindwright/.claude-plugin/marketplace.json
          
            
      
            2. 
      
          2. 
        
            En cada proyecto
          Abre Claude Code en la carpeta del proyecto y ejecuta la configuración. Hace unas preguntas y no cambia nada sin tu sí.
            
        
            /bindwright:setup
          
            
      
            3. 
    
          
    
            
      
          1. 
        
            Abre tu proyecto
          En la pestaña Code, inicia una sesión nueva en la carpeta de tu proyecto.
            
      
            2. 
      
          2. 
        
            Instala Bindwright
          Pega esto y envíalo, y espera a que Claude diga que terminó. No necesita Git.
            
        
            Instálame el plugin Bindwright: ejecuta claude plugin install bindwright --marketplace https://starfoxcom.github.io/bindwright/.claude-plugin/marketplace.json en la terminal. Si no encuentra claude, agrega ese marketplace (llamado bindwright, con origen url) en extraKnownMarketplaces y "bindwright@bindwright": true en enabledPlugins de ~/.claude/settings.json, sin tocar lo demás.
          
            
      
            3. 
      
          3. 
        
            Ejecuta la configuración
          Inicia otra sesión nueva en la misma carpeta, para que cargue el plugin, y ejecuta esto. En tus siguientes proyectos, solo haces este paso.
            
        
            /bindwright:setup
          
            
      
            4. 
    
          
    
          
      
          
        
          Se pregunta una vez en tu computadora
          
        
          Búsqueda de código, reglas de trabajo compartidas, una protección contra force push, un modelo ayudante barato para el código, tu estilo de código y los mods. Cámbialos después con /bindwright:setup global.

          Quién trabaja en él, si es privado o público, qué revisiones corren, cómo trabaja el asistente y dónde vive el plan.
