Deja de explicarle tu proyecto a Claude cada vez.

Bindwright escribe las reglas que Claude Code lee al inicio de cada sesión y agrega una revisión con IA a cada pull request, así cada sesión ya sabe cómo trabajas, y toda la configuración es un solo comando.

Instalar Bindwright Ver en GitHub

Qué cambia

  • Claude olvida cómo trabajas en cada sesión Claude deja de repetir errores Lee tus reglas al inicio de cada sesión, así las funciones pequeñas y las pruebas reales dejan de ser algo que tienes que pedir cada vez.
  • Los cambios se integran sin que nadie los revise Cada pull request se revisa Una IA revisa cada cambio antes de integrarlo, y si la revisión no pasa, nada entra.
  • Cada sesión empieza desde cero Las sesiones siguen donde se quedaron Cada sesión empieza con un plan y termina con una nota para la siguiente, así el trabajo sigue justo donde se quedó.
  • Un comando equivocado puede borrar tu rama principal Los comandos peligrosos se bloquean Los push forzados a tu rama principal se detienen antes de ejecutarse, ya que un comando equivocado ahí te puede costar días de trabajo.

Lo que escribe una configuración

Se muestra para el proyecto público de una sola persona con todo activado. La configuración lo ajusta al tuyo según tus respuestas.

    
            
    
          
    
        
    
      
    
    
    
  
    

  
    
    
    Instalar
    
    
    Dos comandos una vez en tu computadora, y luego uno en cada proyecto. Pega cada uno en Claude Code, presiona Enter y espera a que termine antes del siguiente.
    
    
    
    
    
    
    En tu computadora, una vez
    
    
      
      
    1. 
        
      Dile a Claude Code de dónde viene Bindwright.
          Esto agrega el marketplace de Bindwright, una lista desde la que Claude Code puede instalar. Todavía no instala nada.
      
        
      /plugin marketplace add starfoxcom/claude-code-templates
          
      
      
      2. 
      
    2. 
        
      Instala Bindwright.
          Esto agrega los comandos /bindwright a todos los proyectos de tu computadora, más un aviso una vez al día cuando algo esté desactualizado. Todavía no cambia ningún proyecto.
      
        
      /plugin install bindwright@bindwright
          
      
      
      3. 
    
    
    
    
    
    
    
    En cada proyecto
    
    
      
      
    1. 
        
      Abre Claude Code en la carpeta del proyecto.
          La configuración escribe en la carpeta donde está abierto Claude Code.
      
      
      2. 
      
    2. 
        
      Ejecuta la configuración.
          Hace unas preguntas y luego escribe los archivos que encajan. Nada de lo que ya tienes cambia sin tu sí.
      
        
      /bindwright:setup
          
      
      
      3. 
    
    
    
    
    
    
    
    
      
    
        
    Se pregunta una vez en tu computadora
    
        
    Qué herramienta de búsqueda de código usar, si agregar las reglas de trabajo de Bindwright a todos los proyectos, un guardia contra force push en todos los proyectos y qué mods agregar. Cámbialas después con /bindwright:setup global.
    
      
    
      
    
        
    Se pregunta en cada proyecto
    
        
    Quién trabaja en él, de quién es, si es privado o público, si el crédito de la IA queda fuera de los commits, qué revisiones corren, cómo escribe y trabaja el asistente, y dónde vive el plan: un tablero de GitHub, issues o un archivo de traspaso.
