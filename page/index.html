What changes

  • Claude forgets how you work every session Claude stops repeating mistakes It reads your rules at the start of every session, so small functions and real tests stop being something you have to ask for every time.
  • Changes merge without anyone checking them Every pull request gets reviewed An AI reviews every change before it merges, and if the review doesn't pass, nothing goes in.
  • Each session starts from scratch Sessions pick up where they stopped Each session starts with a plan and ends with a note for the next one, so the work picks up right where it stopped.
  • One wrong command can wipe your main branch Risky commands get blocked Force pushes to your main branch get stopped before they run, since one wrong command there can cost you days of work.
  • The priciest model writes every line A cheap helper writes the code A small, cheap model writes code your tests can prove, and the main model plans it and checks the result. In 24 measured jobs across two projects, 23 passed every check on the first try, for an estimated third of the cost. You can turn it off at setup.
  • You have to babysit CI and the plan limits It keeps working while you're away It watches CI and merges once every check passes, pauses near your plan limit and picks back up after the reset, and carries your words across a full context, so the work keeps moving without you.
  • Claude opens file after file to find one function It finds code before reading it A code-search tool indexes your code, so on big codebases it finds a function and its callers about a quarter faster, for a few percent more tokens. You can keep the built-in search instead.
  • Its code doesn't look like yours It writes the way you do With your permission it learns how you write code from your repos, then writes that way with the weak spots fixed, and the docs it writes use plain words instead of jargon.

          Mistakes that became rules
          
    
          
      
          What went wrongWhat Bindwright does now
          
      
        
          The task board went public, internal engineering notes and all.Checks the board's visibility on every read and warns when it's public.
          
        
          Functions 273 lines long shipped, because the size rule never loaded.A size check fails any pull request with an overlong function.
          
        
          Two pull requests took 22 and 30 rounds: every fix gave the reviewer something new to flag.A finding blocks only when the change caused it; older gaps become their own issues.
          
        
          A hotfix merged into main never reached develop.A hotfix counts as done only once it's back in develop.
          
        
          A pull request merged with the deeper review it had asked for still pending.Once a deeper review is asked for, nothing merges until it passes.
          
        
          A workflow change made on a feature branch failed its own check.Workflow changes land on main first, then flow back to develop.
          
        
          A review model picked from one round of tests blocked clean pull requests in five of nine reviews once the test ran three times.Review models are picked by best-of-three trials, with the current model in the same run (every trial).

          Install
          
    
          
      
      
    
          
    
          
    
            
      
          1. 
        
            On your computer, once
          Adds the /bindwright commands to every project, ready in this session. Needs no Git.
            
        
            /plugin install bindwright --marketplace https://starfoxcom.github.io/bindwright/.claude-plugin/marketplace.json
          
            
      
            2. 
      
          2. 
        
            In each project
          Open Claude Code in the project's folder and run setup. It asks a few questions and changes nothing without your yes.
            
        
            /bindwright:setup
          
            
      
            3. 
    
          
    
            
      
          1. 
        
            Open your project
          In the Code tab, start a new session in your project's folder.
            
      
            2. 
      
          2. 
        
            Install Bindwright
          Paste this and send it, then wait until Claude says it is done. Needs no Git.
            
        
            Install the Bindwright plugin: run claude plugin install bindwright --marketplace https://starfoxcom.github.io/bindwright/.claude-plugin/marketplace.json in the shell. If claude is not found, add that marketplace (named bindwright, a url source) under extraKnownMarketplaces and "bindwright@bindwright": true under enabledPlugins in ~/.claude/settings.json, keeping the rest.
          
            
      
            3. 
      
          3. 
        
            Run the setup
          Start another new session in the same folder, so the plugin loads, and run this. In your next projects, this is the only step.
            
        
            /bindwright:setup
          
            
      
            4. 
    
          
    
          
      
          
        
          Asked once on your computer
          
        
          Code search, shared working rules, a force-push guard, a cheap helper model for code, your coding style and mods. Change them later with /bindwright:setup global.
          
      
          
      
          
        
          Asked in every project
          
        
          Who works on it, private or public, which checks run, how the assistant works, and where the plan lives.
