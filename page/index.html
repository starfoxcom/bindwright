Stop re‑explaining your project to Claude.

Bindwright writes the rules Claude Code reads at the start of every session and sets up an AI review on every pull request, so each session already knows how you work, and the whole setup is just one command.

Install Bindwright View on GitHub

What changes

  • Claude forgets how you work every session Claude stops repeating mistakes It reads your rules at the start of every session, so small functions and real tests stop being something you have to ask for every time.
  • Changes merge without anyone checking them Every pull request gets reviewed An AI reviews every change before it merges, and if the review doesn't pass, nothing goes in.
  • Each session starts from scratch Sessions pick up where they stopped Each session starts with a plan and ends with a note for the next one, so the work picks up right where it stopped.
  • One wrong command can wipe your main branch Risky commands get blocked Force pushes to your main branch get stopped before they run, since one wrong command there can cost you days of work.

What a setup writes

Shown for one person's own public project with everything on. Setup fits it to yours from your answers.

    
            
    
          
    
        
    
      
    
    
    
  
    

  
    
    
    Install
    
    
    Two commands once per computer, then one in each project. Paste each into Claude Code, press Enter and let it finish before the next.
    
    
    
    
    
    
    On this computer, once
    
    
      
      
    1. 
        
      Tell Claude Code where Bindwright comes from.
          This adds Bindwright's marketplace, a list Claude Code can install from. It installs nothing yet.
      
        
      /plugin marketplace add starfoxcom/claude-code-templates
          
      
      
      2. 
      
    2. 
        
      Install Bindwright.
          This adds the /bindwright commands to every project on this computer, plus a once-a-day note when something is out of date. It changes no project yet.
      
        
      /plugin install bindwright@bindwright
          
      
      
      3. 
    
    
    
    
    
    
    
    In each project
    
    
      
      
    1. 
        
      Open Claude Code in the project's folder.
          Setup writes into the folder Claude Code is open in.
      
      
      2. 
      
    2. 
        
      Run the setup.
          It asks a few questions, then writes the files that fit. Nothing you already have changes without your yes.
      
        
      /bindwright:setup
          
      
      
      3. 
    
    
    
    
    
    
    
    
      
    
        
    Asked once per computer
    
        
    Which code-search tool to use, whether to add Bindwright's working rules to every project, a guard against force pushes in every project, and which mods to add. Change them later with /bindwright:setup global.
    
      
    
      
    
        
    Asked in every project
    
        
    Who works on it, whose it is, private or public, whether AI credit stays out of commits, which checks run, how the assistant writes and works, and where the plan lives: a GitHub board, issues or a hand-off file.
