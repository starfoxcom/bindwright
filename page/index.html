What changes

  • Claude forgets how you work every session Claude stops repeating mistakes It reads your rules at the start of every session, so small functions and real tests stop being something you have to ask for every time.
  • Changes merge without anyone checking them Every pull request gets reviewed An AI reviews every change before it merges, and if the review doesn't pass, nothing goes in.
  • Each session starts from scratch Sessions pick up where they stopped Each session starts with a plan and ends with a note for the next one, so the work picks up right where it stopped.
  • One wrong command can wipe your main branch Risky commands get blocked Force pushes to your main branch get stopped before they run, since one wrong command there can cost you days of work.
  • The priciest model writes every line A cheap helper writes the code A small, cheap model writes code your tests can prove, and the main model plans it and checks the result. In 24 measured jobs across two projects, 23 passed every check on the first try, for an estimated third of the cost. You can turn it off at setup.
  • You have to babysit CI and the plan limits It keeps working while you're away It watches CI and merges once every check passes, pauses near your plan limit and picks back up after the reset, and carries your words across a full context, so the work keeps moving without you.
  • Claude opens file after file to find one function It finds code before reading it A code-search tool indexes your code, so on big codebases it finds a function and its callers about a quarter faster, for a few percent more tokens. You can keep the built-in search instead.
  • Its code doesn't look like yours It writes the way you do With your permission it learns how you write code from your repos, then writes that way with the weak spots fixed, and the docs it writes use plain words instead of jargon.

          Install
          
    
          Two commands once on your computer, then one in each project. Paste each into Claude Code, press Enter and let it finish before the next.
          
    
          
    
          
    
          On your computer, once
          
    
            
      
          1. 
        
            Tell Claude Code where Bindwright comes from.
          This adds Bindwright's marketplace, a list Claude Code can install from. It installs nothing yet.
            
        
            /plugin marketplace add starfoxcom/bindwright
          
            
      
            2. 
      
          2. 
        
            Install Bindwright.
          This adds the /bindwright commands to every project on your computer, plus a once-a-day note when something is out of date. It changes no project yet.
            
        
            /plugin install bindwright@bindwright
          
            
      
            3. 
    
          
    
          
    
          
    
          In each project
          
    
            
      
          1. 
        
            Open Claude Code in the project's folder.
          Setup writes into the folder Claude Code is open in.
            
      
            2. 
      
          2. 
        
            Run the setup.
          It asks a few questions, then writes the files that fit. Nothing you already have changes without your yes.
            
        
            /bindwright:setup
          
            
      
            3. 
    
          
    
          
    
          
    
          
      
          
        
          Asked once on your computer
          
        
          Which code-search tool to use, whether to add Bindwright's working rules to every project, a guard against force pushes in every project, whether a cheap helper model writes the code the main model plans, whether to learn your coding style from code you wrote by hand, and which mods to add. Change them later with /bindwright:setup global.
          
      
          
      
          
        
          Asked in every project
          
        
          Who works on it, whose it is, private or public, whether AI credit stays out of commits, which checks run, how the assistant writes and works, and where the plan lives: a GitHub board, issues or a hand-off file.
